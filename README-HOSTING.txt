PENTING UNTUK INFINITYFREE
1. Upload ISI folder sistem-mahasiswa ke folder htdocs/public_html yang dipakai domain.
2. Jika mengganti versi lama, hapus file lama terlebih dahulu agar config/database.php dan file lain tidak tertinggal.
3. Buka https://DOMAIN-KAMU/health.php
4. Jika health.php tampil, buka https://DOMAIN-KAMU/setup.php
5. Isi MySQL Host, Database Name, Username, Password dari menu MySQL Databases InfinityFree.
6. Setelah sukses, buka /auth/login.php.
7. Hapus setup.php dan health.php setelah selesai.
